Лабораторная работа №1
Определение операционной системы и сбор информации о ней.
Цель работы:
Разработать программу на Python, которая:
1. определяет операционную систему, на которой запущена программа;
2. собирает основные параметры текущей операционной системы;
3. сохраняет полученную информацию в файл формата JSON.

Описание работы программы:
Программа определяет операционную систему с помощью стандартного модуля “platform”.

Поддерживаются следующие операционные системы:
* Windows;
* Linux;
* macOS.
После определения операционной системы программа собирает информацию о системе и сохраняет её в файл “os_info.json”.

Собираемые параметры
Программа получает следующие параметры:
Параметр	Описание
“operating_system”	название операционной системы
“release”	релиз операционной системы
“version”	версия операционной системы
“platform”	подробное описание платформы
“architecture”	архитектура компьютера

 Используемые модули
В программе используются только стандартные модули Python.
“platform”
Используется для получения информации об операционной системе:
* “system()” — определяет тип ОС;
* “release()” — получает релиз ОС;
* “version()” — получает версию ОС;
* “platform()” — формирует подробное описание платформы;
* “machine()” — определяет архитектуру компьютера.
“os”
Используется для работы с путями:
* “path.abspath()” — получает абсолютный путь;
* “path.dirname()” — получает директорию программы;
* “path.join()” — объединяет части пути.

 “json”
Используется для сохранения собранной информации в формате JSON.

Внешние библиотеки не используются, потому что стандартных модулей Python достаточно для выполнения поставленной задачи.

Ограничения:
В соответствии с условием лабораторной работы программа не использует стандартные утилиты операционной системы.
Не используются такие команды, как:
* “systeminfo”;
* “wmic”;
* “uname”;
* “lsb_release”.
Информация получается непосредственно средствами стандартной библиотеки Python.

Запуск программы:
Для запуска необходимо открыть терминал в папке с программой и выполнить:
python my_script.py

Результат работы:
После запуска программа выводит информацию в терминал:
Информация успешно сохранена!
Файл: .../os_info.json
Операционная система: Windows
Также в папке с программой автоматически создаётся файл:
os_info.json

Вывод:
В ходе лабораторной работы была разработана программа на Python, которая определяет операционную систему и собирает основные сведения о ней.
Полученная информация сохраняется в структурированном формате JSON.

При выполнении работы были использованы только стандартные модули Python, поэтому установка дополнительных библиотек не требуется.
